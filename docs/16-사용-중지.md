# 16. 로봇·사업장 사용 중지 (2026-11-07)

사용자 요청: "로봇 관제에서 vdf 를 빼줘 더이상 사용하지 않는 기기야. 광양포항 POC 사업장도 아예 빼줘."

## 1. 왜 '삭제'가 아니라 '사용 중지'인가
- 로봇·사업장에는 실적·장애·명령·보고서 이력이 묶여 있다(외래 키). 지우면 과거 보고서·감사 기록이 깨지므로 **운영에서만 빼고 이력은 보존**한다(HANDOFF 원칙: 이력 보존·감사 기록).
- 로봇 자체(제조사 등록·지도)에는 아무것도 보내지 않는다. 이 시스템이 감시·명령을 멈출 뿐이다.

## 2. 동작
| 대상 | 하는 일 | 남는 것 |
|---|---|---|
| 로봇 사용 중지 (`robots.active=false`) | 상태 동기화·로봇 목록·대시보드·사업장 지도·작업 등록 대상·보고서 운영 대수에서 제외. 명령은 서버에서 거부(감사 `COMMAND:* DENIED "사용 중지된 로봇"`). 미래 예정 회차 취소. 작업 중(청소·일시정지)이면 거부 | 실적·장애·명령 이력, 로봇 상세 화면(안내 문구 + 이력) |
| 사업장 사용 중지 (`sites.retired_at`) | 권한 계산(`allSiteIds`)에서 빠져 **모든** 운영 화면·명령·보고서 목록·알림 수신 설정·원격 제어 설정에서 제외. 보고서 자동 일정·미조치 확대 통보 건너뜀. 그 사업장 로봇 전부 사용 중지, 미래 예정 회차 취소, 원격 제어 끔 | 사업장·층·지도·로봇·실적·장애·보고서(확정본 포함). 고급 설정 카드에 '사용 중지' 표시 |
| 다시 사용 | 사업장: 운영 화면에 복귀(로봇은 중지 상태 유지 → 필요한 로봇만 따로 켬). 로봇: 다음 동기화부터 상태 수신 | — |

- 모두 본사 관리자만, **사유 필수**, 감사 기록 `ROBOT:DEACTIVATE / ROBOT:ACTIVATE / SITE:RETIRE / SITE:RESTORE`.
- 화면: 고급 설정 → 사업장 카드의 『사용 중지』(샘플 사업장 제외) / 『로봇 사용 중지 / 다시 사용』 표. 서버 일회성: `scripts/retire.ts robot|site|robot-restore|site-restore <ID> "<사유>"`.
- 중지된 사업장의 확정 보고서는 운영 화면에서 보이지 않는다. 다시 보려면 '다시 사용' 후 조회한다(결정 필요 시 '이력 열람' 화면을 따로 만들 수 있음).

## 3. 운영 반영 (2026-11-07)
1. 배포(마이그레이션 0011 `sites.retired_at`), 배포 전 점검 오류 0, health ok.
2. `vdf`(PW-R-003, 포스코센터 '테스트' 층, SN 888045912070001) 사용 중지. 포스코센터는 1층·2층 로봇 2대로 운영.
3. `광양포항 POC`(site-poc) 사용 중지 — 로봇 2대(영남 테스트 5호기, 포항습식) 중지, 예정 회차 1건 취소. 이로써 새 키로 조회되지 않던 `포항습식` 문제(`docs/15` 4장)도 해소(더 이상 조회하지 않음).
4. 서버 `PUDU_SHOP_IDS` 에서 광양포항 매장(611150001)을 뺌 → 허용 매장 3곳(선릉센터·이앤씨 단기·성남분당). 워커: `PUDU status: 로봇 6대 중 갱신 6, 실패 0`.
5. 운영 사업장 3곳·로봇 6대 체제. 원격 제어는 여전히 모두 꺼짐.

## 4. 시험
- 93개 통과(추가 2건): 로봇 사용 중지 — 본사만·사유 필수·작업 중 거부·목록/대시보드 제외·상세는 이력·명령 DENIED 감사·예정 회차 취소·이력 건수 불변·다시 사용. 사업장 사용 중지 — 권한/목록/대시보드 제외·로봇 전부 중지·원격 제어 끔·실적/장애/보고서 보존·자동 일정 제외·확대 통보 제외·다시 사용 시 로봇 중지 유지.
- 브라우저(샘플): 고급 설정 로봇 표에서 '사용 중지'(사유 입력) → 표에 '사용 중지·다시 사용' 표시, 로봇 목록에서 사라짐, 로봇 상세에 안내 문구. 콘솔 오류 없음.
