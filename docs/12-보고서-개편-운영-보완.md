# 12. 보고서 개편 · 운영 보완 (2026-10-30)

사용자 요청 두 묶음을 처리했다.
- 보고서: 버튼 작성 유지, 설치 완료보고서를 "어떻게 청소할지" 계획 중심으로(지도 위 청소 범위·사진·주간 예약), 실적 데이터 채우기와 영구 보관, PDF 외에 편집 가능한 PPT·Excel, 웹에서 수치 수정.
- 운영: 작업·일정 필터, 장애 단계별 되돌리기, 불필요 알림 삭제와 경과 시간 표시, 다른 사업장 지도 표시.

## 1. 실적 데이터 채우기
- **원인**: 연동은 최근 48시간만 받아 왔고(10/27 이후 실적만 있음), PUDU 예약을 계획 회차로 만드는 기능이 없어 계획 완료율이 늘 "해당 없음"이었다.
- **과거 실적 적재** `scripts/pudu-backfill.ts`: 청소 보고서·장애 로그를 7일 구간씩 거슬러 받는다(멱등, 실패 구간 재시도). **PUDU 통계 API 는 최근 180일만 준다** → 2026-05-03 이전(예: 포스코센터 설치일 4/13~5/2)은 받을 수 없다. 이 때문에 받은 데이터는 우리 DB 에 영구 보관하는 것이 중요하다.
- 과거 장애 로그(7일보다 오래된 것)는 조치 대상이 아니라 이력이므로 '복구' 상태로 넣고 "제조사 장애 로그 이력에서 적재(조치·복구 기록 없음)" 를 조치 기록에 남긴다(미조치 목록이 수백 건으로 넘치지 않게).
- **계획 회차**: 워커가 10분마다 PUDU 예약으로 오늘·내일 회차를 만들고, 예정 시각 3시간이 지나면 같은 로봇의 실적(±90분)과 맞춰 수행/미실행으로 판정한다(`syncPuduPlannedRuns`). 지금 예약으로 과거 회차를 소급하지 않는다(그때 예약이 지금과 같다는 보장이 없음) → 과거 기간의 계획 완료율은 "해당 없음"으로 남는다.

## 2. 보관
- 보고서·사진·실적·장애·감사 기록을 지우는 코드는 없다(보존 기한 없음). 지우는 것은 처리 끝난 콜백 원문(30일)과 만료 세션뿐.
- 보고서에 지도가 실린 층은 삭제할 수 없다(지도·이미지 보존).
- 백업: 일일 덤프 14일 + **월별 보관본(`backups/monthly`) 영구**, Lightsail 스냅샷.

## 3. 보고서
| 기능 | 내용 |
|---|---|
| 작성 | 일정표의 버튼으로만 만든다(자동 작성 기본 끔, `REPORT_AUTO_DRAFT`) |
| 설치 완료보고서 | 1쪽: 단계 일정 화살표(기본: 설치·맵핑 D0 → 운영·세부 조정 D+1~6 → 안정화 D+7~21 → 정상 운영, 고칠 수 있음) + 설치 총평. 2쪽: 현장 사진 + 층별 지도 위 청소 구역(제조사 지도의 area). 3쪽: 주간 예약 타임라인(요일 × 0~24시, 막대 길이 = 최근 실적 평균 소요) + 설치 로봇. 4쪽: 작업 일지(구분·담당·작업 내용) 와 보완 사항. 실적 수치·등록 작업 전체 목록은 뺐다 |
| 사진 | 모든 보고서에 첨부 가능(설치 보고서는 지도와 같은 쪽). 브라우저에서 긴 변 1600px JPEG 로 줄여 올림, 설명 수정·삭제는 초안·검토 상태에서만, 확정 뒤 고정. 고객은 공개본의 사진만. 새 버전은 사진·작업 일지·단계 일정을 이어받는다 |
| 수치 수정 | 초안·검토 상태에서 『수치 수정』 → 요약·계획 대비·일자별·층·구역·로봇·점검 수치를 고칠 수 있다. 원래 집계값은 보존, 고친 값은 * 표시(고객에게도 "담당자가 현장 기록으로 확인해 보정" 주석), 되돌리기, 감사 기록 `REPORT:ADJUST`. 완료율은 고친 분자·분모로 다시 계산. 새 버전은 보정값을 이어받지 않는다(새 집계가 기준) |
| 내려받기 | PDF = 화면의 'PDF 출력(인쇄)'. **PPT**(.pptx): 표는 PPT 표, 청소 구역은 다각형 도형, 사진·지도 이미지 포함 — 설치 보고서 1장은 첨부 양식(지도·사진 4장·작업 일지·단계 화살표)과 같은 배치. **Excel**(.xlsx): 시트별(요약·일자별·층별·로봇별·장애·점검·작업 일지·주간 예약·청소 구역·지도·사진), 담당자 내려받기에만 '보정 내역'(원래값) 시트. 감사 기록 `REPORT:EXPORT` |

## 4. 운영 화면
- **작업·일정**: 등록 작업·예약 카드에 『예약된 작업만 / 등록 작업 포함』 필터(기본 예약된 작업만, 사업장 필터와 함께 주소에 남는다).
- **장애·조치**: 『↶ 한 단계 되돌리기』(복구 취소 → 마지막 조치 취소 → 담당자 지정 취소 → 확인 취소, 사유 필수), 조치 기록마다 『취소』. 모두 감사 기록(`INCIDENT:REVERT`, `INCIDENT:ACTION_CANCEL`)에 원래 내용과 함께 남는다.
- **불필요 알림 삭제**: 체크 후 사유를 적고 『선택한 알림 삭제』. 목록·대시보드·보고서에서 빠지고, 행은 남겨 같은 제조사 이벤트가 다시 생기지 않는다. 『삭제한 알림 보기』에서 사유 확인, 본사 관리자가 복원.
- **경과 시간**: 미조치·소요 시간을 분 → 시간 → 일 단위로(예: 45분, 2시간 15분, 1일 6시간).
- **다른 사업장 지도**: 원인은 그 층들에 PUDU 지도를 가져오지 않았고(포스코센터 1·2층만 있었음), 층 지도가 없으면 로봇이 쓰는 지도 이름도 버려서 화면이 안내하지 못했던 것. 이제 로봇이 쓰는 지도 이름을 남겨 사업장 관제에 "층 지도 맞추기" 안내를 띄우고, 관리 설정 → PUDU 패널 『로봇이 쓰는 지도로 층 지도 맞추기』(서버: `scripts/align-floor-maps.ts`)가 층마다 로봇이 쓰는 지도를 가져온다. 한 층의 로봇들이 서로 다른 지도를 쓰면(예: 2단지 도로면/주차면) 다수결로 고르고 층을 나누도록 알린다.

## 5. 시험
- 단위·통합 시험 82개(10 파일) 통과: 수치 보정(원래값 보존·완료율 재계산·되돌리기·권한·확정 뒤 불가·새 버전), 설치 보고서 스냅샷(지도·주간 예약)·단계 일정 검증·사진(형식 검사·권한·확정 뒤 고정·새 버전 승계)·PPT/Excel 생성·지도 실린 층 삭제 차단, 장애 되돌리기 5단계·조치 취소·알림 삭제/재수신 무시/복원 권한·경과 표시, 과거 이력 적재(복구 상태·묶음), 계획 회차 생성·판정, 층 지도 맞추기.
- 브라우저 확인(샘플 데이터): 사진 올리기(1600px 축소), 단계 일정 저장, 지도 2개·주간 예약 표시, PPT·Excel 내려받기, 수치 수정 → * 표시, 작업 필터, 경과 표시·되돌리기·선택 삭제·삭제한 알림 보기, 모바일 390px 가로 넘침 없음.
- PPT 는 LibreOffice 로 그림으로 바꿔 배치를 확인했다(PowerPoint 실물에서는 아직 열어 보지 않았다). 글꼴은 '맑은 고딕' 으로 지정했다.
