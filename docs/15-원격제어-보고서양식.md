# 15. 사업장별 원격 제어 스위치 · 보고서 PPT/Excel 양식 개편 (2026-10-31)

## 1. 원격 제어(사업장별)
- 관리 설정 → **원격 제어 (사업장별)**: 사업장마다 켜기/끄기(사유 입력, 감사 기록 `SITE:REMOTE_CONTROL`). 본사 관리자만.
- 꺼진 사업장: 본사 관리자를 포함해 **누구도** 로봇에 원격 명령을 보낼 수 없다(서버에서 거부, 감사 기록 `COMMAND:*` DENIED "사업장 원격 제어 꺼짐"). 로봇 화면은 명령 버튼 대신 안내 문구.
- 켜져 있어도 사용자별 제어 권한·상태 규칙·5분 상태 신선도·중복 시작 방지는 그대로 적용된다.
- **기본값은 꺼짐**(마이그레이션 0010). 운영 사업장 4곳은 배포 직후 모두 꺼진 상태로 시작한다 — 필요한 사업장만 켠다. 샘플 사업장은 시연용으로 켜짐.

## 2. 보고서 양식 개편
사용자 피드백 "PPT 와 엑셀 양식이 이상하다" → 4종(설치·일간·주간·월간)을 실제로 만들어 그림으로 확인하며 고쳤다.

| 문제(이전) | 개편 |
|---|---|
| 장마다 작은 표만 왼쪽 위에 있고 대부분 빈 공간, 일간이 7장 | 일간 3장 이내: 1장에 핵심 수치 카드 6개 + 작업 일지 + 작업 목록 + 의견 3칸 |
| 표가 넘쳐 자동으로 생긴 장에 머리띠가 없음 | 슬라이드 마스터로 모든 장에 같은 머리띠(사업장·보고서·기간)·꼬리(버전·집계 시각·쪽 번호) |
| 수치가 표 한 칸에 문장으로 | 핵심 수치 카드(운영 대수·완료율·총 작업·면적·시간·장애, 보정 * 표시) |
| 일자별 추이를 볼 수 없음 | 주간·월간 1장에 **PPT 차트**(일자별 누적 면적, 데이터 편집 가능) + 종합 의견 |
| 월간 일자별 30행이 넘쳐 다음 장으로 | 일자별 실적 장을 두 단(16일씩)으로, 합계 줄 |
| 오른쪽 표가 장 밖으로 잘림 | 층·로봇·구역별을 따로 한 장 |
| 숫자에 천 단위 쉼표 없음 | 모든 수치 천 단위 쉼표, 숫자 열 오른쪽 정렬, 줄무늬 |
| 엑셀 요약 시트 제목·항목 잘림, 값이 멀리 떨어짐 | 지표·값·단위·비고 표(테두리·숫자 서식), 의견은 병합 셀 줄바꿈 |
| 엑셀 표 서식 없음 | 모든 표: 머리 행 색·테두리·`#,##0` 서식·필터·틀 고정·가로 1쪽 너비 인쇄, 일자별에 요일·합계(수식) |

- 설치 완료보고서 1장(지도·사진 4장·작업 일지·단계 화살표)은 첨부 양식 배치를 유지하고 머리띠만 통일했다.
- 확인 방법: 샘플 데이터로 4종 생성 → LibreOffice 로 그림 변환해 장마다 확인(PowerPoint·Excel 실물로는 아직 열어 보지 않음).

## 3. 시험
- 91개 통과(원격 제어: 꺼지면 본사도 거부·감사 기록·사유 기록·본사 외 변경 불가·다시 켜면 동작).
- 브라우저: 관리 설정 원격 제어 표 → 끄기(사유) → 꺼짐 표시, 로봇 화면 안내 문구.
