## 2. 비밀값·접근 수단이 있는 곳 (새 세션에는 없음)
- **PUDU ApiAppKey/Secret**: 서버 `/opt/robot-system/.env` 에만 있다(600 권한). 저장소·문서·대화에 없다. 2026-11-07 사용자가 재발급한 새 키로 교체했다(`docs/15` 4장) — 바꿀 일이 있으면 `scripts/remote-env.sh "PUDU_API_APP_KEY=…" "PUDU_API_APP_SECRET=…"` 로 서버 값만 고친다. 사용자에게 키를 다시 보내 달라고 하지 않는다.
- **DB 비밀번호·기타 .env**: 서버 `.env` 에만 있다. 값이 필요하면 서버에서 쓰는 작업(`remote-run.sh`)으로 처리하고, 바깥으로 꺼내지 않는다.
- **AWS 자격 증명**: 브라우저 로그인(12시간 만료). 새 세션마다 `scripts/setup-aws-cli.sh` → `scripts/aws-login-remote.sh start` 로 URL 을 내고, 사용자가 브라우저에서 받은 인증 코드를 대화로 주면 `aws-login-remote.sh code <코드>` 로 넣는다. 코드는 저장하지 않는다.
- **서버 작업 채널**: SSH 가 아니라 **SSM Run Command**(관리 인스턴스 `mi-0d6dbe7bc429007bf`, 역할 `WidebotSSMServiceRole`). 비공개 S3 버킷 `widebot-deploy-315899575985`(30일 자동 삭제)를 파일 전달용으로 쓴다. AWS 프로젝트 315899575985, 리전 **ap-southeast-2 만** 사용 가능(서울 불가, `CLAUDE.md`).
- **운영 초기 구성 spec**(실제 SN·매장 ID): 저장소에 없고(`ops-*.json` 무시) 서버 DB 에 이미 반영돼 있다. 다시 필요하면 관리 설정 화면이나 DB 에서 본다.
- 사용자 이메일: mylightelf@gmail.com (관리자 계정, 인증서 알림 `ACME_EMAIL`).

## 3. 새 세션에서 쓰는 명령
```bash
# 0) 로컬 DB(이 작업 환경은 컨테이너 재시작 시 Postgres 가 내려감)
service postgresql start; npm install; npm test            # 64개 통과가 기준

# 1) AWS (서버 작업 전 매번)
./scripts/setup-aws-cli.sh                                  # CLI 설치·리전 설정(이미 있으면 건너뜀)
./scripts/aws-login-remote.sh start                         # URL 출력 → 사용자에게 전달
./scripts/aws-login-remote.sh code <사용자가 준 인증코드>    # 로그인 확인
export PATH="$HOME/.local/bin:$PATH"

# 2) 서버 상태 보기
./scripts/remote-run.sh <<'EOS'
cd /opt/robot-system && docker compose ps && curl -s http://127.0.0.1:3000/api/health; echo
docker compose logs worker --no-color --tail 30
EOS

# 3) 서버 .env 값 바꾸기(값은 S3 presigned 로 전달, 이력에 안 남음) → web/worker/caddy 재기동 + health 확인
./scripts/remote-env.sh ACME_EMAIL=mylightelf@gmail.com
./scripts/remote-env.sh PUDU_CALLBACK_CODE=<대리점이 준 코드>

# 4) 코드 배포(현재 HEAD → 서버 빌드, 5~10분)
./scripts/deploy-remote.sh
```
서버 안의 일회성 스크립트는 워커 이미지로 실행한다: `docker compose run --rm worker npx tsx scripts/bootstrap-admin.ts "이름" 이메일`. 과거 실적 적재는 `scripts/pudu-backfill.ts --from YYYY-MM-DD`, 그 뒤 초안 숫자 맞추기는 `scripts/recompute-drafts.ts`(둘 다 멱등). 아직 이미지에 없는 스크립트는 `-v /opt/robot-system/scripts/파일.ts:/app/scripts/파일.ts` 로 마운트해 실행할 수 있다.

## 5. 지켜야 할 것(요약, 원문은 HANDOFF.md·CLAUDE.md)
- 실제 API 모듈과 샘플 모듈 분리. API 주소·응답을 추측해 구현하지 않는다. 시험 안 한 것을 통과했다고 쓰지 않는다. 시뮬레이션 동작은 표시한다.
- 비밀값은 서버 `.env` 에만. 대화·저장소·로그·화면·문서에 넣지 않는다. 샘플 데이터에 실제 고객 정보 없음.
- 고객사에 원시 오류·통신 로그·내부 메모·보고서 초안 노출 금지. 서버 쪽 사업장 범위 검사. 명령 감사 기록.
- 실제 로봇 명령은 사용자가 허락한 조건(충전 중, 지정 로봇)에서만. 지금은 **중지** 상태.
- 사용자는 프로그래밍 초보, 운영 관점. 한국어로, 확정된 요구사항을 다시 묻지 않고, 미정은 제안+근거.
- AWS 자원은 ap-southeast-2 에만 만든다.
