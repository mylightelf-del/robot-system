# 11. 보고서 일정 — 설치·일간·주간·월간 (2026-10-30)

사용자 요구(2026-10-30): "최초 설치되면 설치 완료보고서, D+6일까지 일간보고서, D+7·14·21일 주간보고서 발행, 이후 설치일 차월부터 동일 날짜에 월간 보고서 작성".

## 1. 일정 규칙
설치일(D0)은 사업장마다 관리 설정 → 사업장 → 수정 → **설치일**에 입력한다. 날짜는 사업장 시간대 기준이다.

| 보고서 | 대상 기간 | 초안 자동 작성 |
|---|---|---|
| 설치 완료보고서 | D0 하루 | D0 당일(설치일 입력 즉시) |
| 일간보고서 D+1 ~ D+6 | 그날 하루 | 다음 날 06시 |
| 주간보고서 1·2·3주차 | D+1~D+7, D+8~D+14, D+15~D+21 | D+8, D+15, D+22 06시 |
| 월간보고서 n개월차 | (직전 기준일+1) ~ (설치일 n개월 뒤 같은 날짜) | 기준일 다음 날 06시 |

예) 10/15 설치 → 10/15 설치보고 · 10/16~10/21 일간 6건 · 10/16~22, 10/23~29, 10/30~11/5 주간 · 10/16~11/15, 11/16~12/15 … 월간.

- **해석(가정)**: "D+n 보고서"는 D+n 일까지의 실적을 담는다. 그날 실적이 다 들어와야 하므로 초안은 다음 날 아침에 만든다. 다르게 원하면(예: D+7 주간이 D0~D+6) `src/lib/reports/schedule.ts` 한 곳만 바꾸면 된다.
- 설치일과 같은 날짜가 없는 달(31일 설치 → 2월)은 그 달 말일로 당긴다. 월간 기간은 빈틈·겹침 없이 이어진다(시험으로 확인).
- 1개월차 월간은 D+1부터라 일간·주간과 기간이 겹친다. 월간은 첫 달 전체 요약이다.

## 2. 동작
- **2026-10-30 변경(사용자 결정)**: 초안은 담당자가 일정표의 『초안 만들기』 버튼으로 만든다. 워커 자동 작성은 기본으로 꺼져 있다(`REPORT_AUTO_DRAFT=true` 일 때만 아래처럼 동작).
- (자동 작성을 켠 경우) **워커**가 10분마다 일정을 확인해 초안을 자동으로 만든다(작성자 "자동 작성", 감사 기록 `REPORT:CREATE_DRAFT` 사용자 `system`). 같은 기간에 어떤 버전이든 있으면 만들지 않는다(멱등).
- 자동 작성은 **최근 7일 안**의 일정만 채운다. 설치일을 과거 날짜로 넣어도 지난 보고서가 한꺼번에 쏟아지지 않는다. 그보다 오래된 일정은 실적·보고서 화면의 일정표에서 『초안 만들기』로 만든다.
- 기간이 진행 중인 일정은 『미리 작성』할 수 있다(그때까지 실적으로 집계 → 기간이 끝난 뒤 재집계). 화면에 "기간이 끝나기 전 집계" 경고가 뜬다.
- 이후 흐름은 기존과 같다: 의견 작성 → 검토 요청 → 확정(스냅샷 고정) → 고객 공개. 확정 뒤 늦게 들어온 실적은 같은 기간의 새 버전으로만 반영한다.
- 설치일을 바꾸면 일정이 새 날짜 기준으로 다시 잡힌다. 이미 만든 보고서는 지우지 않고 "일정 밖 보고서"로 남는다. 비우면 일정·자동 작성이 멈춘다.

## 3. 보고서별 내용
| 보고서 | 쪽 구성 |
|---|---|
| 설치 완료 | 요약 + 설치 총평 / 설치 로봇·층·지도·구역·등록 작업·정기 예약(작성 시점 구성, 확정 시 고정) / 설치일 작업(시험 운전)·장애·점검 / 보완 사항·교육·인수인계·안정화 계획 |
| 일간 | 요약 + 일일 의견 / 작업 목록(시각·로봇·층·결과·면적·시간)·계획 대비 수행·미완료 사유 / 장애·점검 / 조치·다음 날 계획 |
| 주간·월간 | 요약 + 종합 의견 / 계획 대비 수행·**일자별 실적**·층·구역·로봇별 / 장애·점검 / 개선·집중 관리·다음 주(차월) 계획 |

의견란 저장 키는 공통이고 이름만 종류별로 다르다(`commentLabels`).

## 4. 화면
- **실적·보고서**: 담당자에게 "처리할 보고서"(작성 필요·초안·검토·확정 미공개, 사업장별) 표. 사업장을 고르면 그 사업장의 전체 일정표(보고서·대상 기간·초안 작성일·상태·열기/초안 만들기). 고객에게는 일정표가 보이지 않고 공개본만 보인다.
- **관리 설정 → 사업장**: 설치일 표시·입력(미등록이면 경고).
