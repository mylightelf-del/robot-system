# 21. 웹 디자인 개편 (2026-11-08)

사용자 요청: "전반적인 디자인을 최신 유행에 맞게 개선해줘."

## 1. 방향
최근 SaaS 관제 화면의 흐름(차분한 회색 바탕 + 흰 카드, 가는 테두리와 부드러운 그림자, 둥근 모서리, 알약형 배지·탭, 가변 글꼴, 숫자 정렬)을 따르되, 기존 네이비 브랜드색과 화면 구조(메뉴·카드 배치)는 그대로 둬서 사용자가 다시 배울 것이 없게 했다. 모든 화면이 공유하는 토큰·공통 컴포넌트만 바꿔 90여 개 화면 요소에 한 번에 적용됐다.

## 2. 바뀐 것
| 영역 | 이전 | 개편 |
|---|---|---|
| 글꼴 | 시스템 글꼴(미지정 변수) | **Pretendard 가변**(jsDelivr CDN, 화면이 뜬 뒤 비동기로 붙임 → CDN 이 막혀도 첫 화면이 멈추지 않고 시스템 한글 글꼴로 대체), 숫자는 tabular-nums |
| 바탕·카드 | 밝은 회색, 카드 `rounded-lg` 얇은 그림자 | 바탕 `#f3f5f9`, 카드 `rounded-2xl` + 가는 테두리 + 부드러운 그림자, 나타날 때 살짝 떠오르는 효과(감속 선호 시 끔) |
| 헤더·메뉴 | 단색 네이비, 밑줄 탭 | 네이비 그라데이션 **고정 헤더**(스크롤해도 유지), 앱 아이콘, **알약형 메뉴**(활성 탭 밝은 배경), 사용자는 이니셜 칩(내 계정 링크) |
| 핵심 숫자 카드 | 흰 카드 | 왼쪽 색 띠(기본·주의·위험·정상), 작은 대문자 라벨, 큰 숫자 |
| 배지 | 네모 | 알약형, 상태 색을 한 단계 옅게(bg-50 / text-700) |
| 표 | 머리 행 회색 | 머리 행 작은 글자·고정(스크롤 시 유지), 행 구분선 옅게, 마우스 올리면 행 강조, 둥근 모서리 |
| 폼 요소 | 화면마다 제각각 | 전역 기본: 둥근 모서리·가는 테두리·파란 포커스 링, 체크박스 강조색, 파일 선택 버튼 정리(기존 인라인 클래스는 그대로 두고도 적용) |
| 버튼 | 네모 | `rounded-lg`, 그림자, 누르면 1px 내려감, 포커스 링 |
| 안내 상자 | 테두리 상자 | 왼쪽 색 띠 + 옅은 바탕 |
| 로그인 | 맨 화면 | 카드 + 앱 아이콘 |
| 오늘 할 일 | 네모 칸 | 왼쪽 색 띠 카드 |
| 테두리 기본색 | currentColor(진함) | 전역 `--border` 연회색 |

## 3. 확인
- 데스크톱 1280px: 대시보드·로봇 목록·로봇 상세·장애·보고서·관리 설정·사업장 관제·로그인 캡처 확인. 콘솔 오류 없음(샌드박스에서 CDN 차단 시 글꼴 요청 실패만 기록되고 화면은 정상).
- 모바일 390px: 대시보드·로봇·장애 가로 넘침 없음.
- 인쇄(보고서 PDF)는 `no-print`·표 머리 고정 해제 유지.

## 4. 다음 후보
- 다크 모드(화면마다 `text-gray-*`·`bg-white` 가 직접 쓰여 있어 토큰으로 바꾸는 작업이 먼저 필요).
- 상태 아이콘을 유니코드 기호에서 SVG 아이콘으로.
